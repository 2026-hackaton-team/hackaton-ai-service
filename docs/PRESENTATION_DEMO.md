### 안전한 프리셋 리허설 순서
1. v4 화면에서 `직장 동료 결혼식` → 기본 추천을 확인한다.
2. **예산 테스트:** 프리셋 실행 후 `예산`을 `30000`으로 수정하고 `추천 계산하고 근거 보기`를 다시 누른다. **프리셋을 다시 누르면 예산이 150000으로 초기화되므로 주의.**
3. `공직자 부조 예외 (가정)` → 조건부 5만원을 확인한다.
4. `계약 심사 이해충돌 (가정)` → 보류 응답을 확인한다.
5. 양방향 직무관계 시연은 **프리셋 직후 시나리오를 `default`로 되돌려야** 실제 프로필/직무 분석 결과를 정책에 반영한다. 가상 시나리오 프리셋에서는 정책 프로필이 별도로 덮어씌워진다.
6. `U001`이 공무원·계약 담당이도록 저장한 뒤 자연어를 입력한다. 입력한 관계 설명은 이름 없이 합성 문장으로 사용하고, **외부 LLM 동의는 해제**한다. 직업 저장은 `내 정보 저장` 버튼을 눌러야 반영된다.
7. 프로필은 세션 사이에도 SQLite에 남는다. 다음 리허설이 이전과 다른 결과를 보인다면 `내 직업`, `기관`, `직무`, 상대 공유동의 및 시나리오 상태를 먼저 확인한다. **DB 파일을 무조건 삭제하지 말 것.**

## 2. 보조·예외 시연 (시간 여유가 있을 때)
- **상대 동의/철회:** v4에서 `U002`로 계정 전환→`직업 정보 이용 허용` 및 `승인된 친구만` 설정·저장→`U001/P001`로 복귀→`상대방 직업정보 이용 상태` 확인. 다시 `U002`에서 허용 해제 후 동일 경로에서 `not_shared` 성격의 안내를 확인. 직업 원문을 다른 계정 화면에 공개하지 않음.
- **직무관련성 모름:** `U001/P001`의 대상이 공직자 분류로 동의 공유되어 있는 경우, 직무 관련성 `모름`, 사실확인 해제 → 확인 질문·송금 보류.
- **동명이인:** 자유상담의 “김도윤” 질문에서 인물 확정 요청이 나오면 관계·소속을 확인. 다른 인물을 이름만으로 자동 연결하지 않음. *자유상담은 실모델 키 필요*.
- **부고 공유 범위:** 계정 `U001`이나 `U012`로 변경 후 일정 페이지에서 카드 확인. 원본 시연 기준일은 `2026-10-30`으로 고정되어 실제 날짜와 다를 수 있음.
- **경조사 범위 밖 질문:** AI 자유 상담에서 날씨 등 질문 → 경조사 범위 안내 기대. *실모델 연결 필요*.

## 3. 실모델 실패 시 대체 시연

- `Codyssey` 키 또는 네트워크 문제로 **AI 자유 상담**이 실패하면 해당 오류를 숨기지 말고 “모델 접속 상태와 별개로 개인정보 경계·법률 근거·금액 계산은 로컬 규칙 검증도 가능합니다”라고 안내하고 **v4 화면**으로 이동.
- v4 화면의 `AI 설명 방식`을 `오프라인 설명만`으로 두고 `외부 LLM 분석 동의`를 체크하지 않은 상태로 통계/법률/관계분석 결과를 시연.
- 실제 외부 LLM 추론을 검증하지 않았다면 “LLM 응답이 확인된 사실이다”라고 말하지 않는다.
- 브라우저 UI가 실패하면 `/v4/api/docs`의 `POST /api/recommend`로 시연 가능하며, 해당 URL은 마운트 경로를 포함한 **`/v4/api/recommend`**에 해당한다.
- 발표 전 네트워크 호출을 포함한 전체 E2E는 발표자 기기에서 직접 수행해야 한다.

## 4. 평가위원 질의응답

**Q. ChatGPT에 축의금 질문하는 것과 무엇이 다른가요?** — 사용자 개인 이력·예산·공개 통계의 근거를 구분하며 직업 동의와 관계 위험을 별도 규칙으로 검사합니다. 특정 법적 판단을 생성형 모델에게 전적으로 맡기지 않습니다.

**Q. 5만원이면 무조건 괜찮나요?** — 아닙니다. 특정 조건에서의 현금 경조사비 **가액 기준**일 뿐이며 예외 요건과 이해관계·기관 규정에 따라 금액 이하도 문제가 될 수 있습니다.

**Q. 사용자의 직업이 진짜인가요?** — 아닙니다. 자기신고 합성 데모이며 실제 신원 인증·재직 증명은 없습니다.

**Q. AI가 추측한 계약 관계를 사실로 판단하나요?** — 아니요. 추정 단서와 사용자가 확인한 조건을 구분하고, 추가 확인 또는 보류로 이어지도록 설계했습니다.

**Q. 외부 LLM에 개인정보가 전송되나요?** — 자유 상담 모드에서는 합성 관계 데이터가 코디세이 모델로 전송될 수 있습니다. v4의 선택적 관계 분석은 동의 시 사용자가 입력한 자유서술을 전송하며, 이름·프로필을 별도 첨부하지 않습니다. **자유서술 자체에 개인정보가 있을 수 있으므로 이름·실제 민감정보를 입력하지 않도록 안내**합니다.

**Q. 상용 서비스인가요?** — 아닙니다. 로그인/실제 인증, 실데이터 보안, 전체 CRUD의 단일 DB 연동, 브라우저 E2E 등은 남아 있습니다.
