> 대상: **원격 `develop`에 병합 완료된 마음결 통합 버전** ([PR #3](https://github.com/2026-hackaton-team/hackaton-ai-service/pull/3)). `main`이나 Windows 단독 `proto_rag_llm` 폴더와 구분하고, 실제 개인정보가 아닌 합성 데이터만 사용합니다.

## 발표 핵심 메시지
**“경조사 금액만 추천하지 않습니다. 내 예산·관계 이력에 근거해 선택을 돕고, 직업·직무상 이해관계가 있으면 추천을 멈추고 확인할 사항을 알려줍니다.”**

- 차별점 1: 개인 관계와 기록 + 공개 설문 근거를 **구분해** 제시
- 차별점 2: **내 직업과 동의받은 상대의 분류**를 함께 고려. 동의 없는 상대 직업은 조회하지 않음
- 차별점 3: 자유서술에 계약·심사 단서가 있으면 체크박스 없이도 위험을 탐지. **미확인 추론과 확인 사실은 구분**
- 차별점 4: 법률 RAG 검색 자료의 검증 상태·체크섬·적용 조건을 확인. **법률 자문이나 적법성 보증 아님**
- 차별점 5: 친구의 친구가 공유한 부고는 공유·참석 허용 조건을 충족할 때만 노출

- [ ] Python FastAPI(8000)와 React(5173)를 실행한다. 실행 절차는 `README.md`를 따른다.
- [ ] `/api/health` 응답의 `status: ok`를 확인한다.
- [ ] React **마음결 AI**에는 자유 상담만 표시되고 별도 v4 화면·iframe이 없는지 확인한다.
- [ ] 가상 계정 `U001`을 선택한 뒤 법률·직무 10개와 감정·관계 10개 시나리오가 보이는지 확인한다.
- [ ] 사용자별 대화 저장·복원, 예산 한도, 동명이인 확인, 법률 위험 보류를 리허설한다.
- [ ] 실제 모델 호출은 별도 Codyssey 키와 네트워크가 필요하다. 오프라인 시나리오는 키 없이 실행한다.
- [ ] 가상 계정은 운영 인증이 아니다. 실제 개인정보와 API 키를 입력하거나 화면에 표시하지 않는다.

### 재현 순서

1. 자유 상담에서 `U001`을 선택하고 새 대화를 시작한다.
2. 감정·관계 10개에서 **금액보다 소중한 친구**를 선택해 추천액과 기준액을 비교한다.
3. 예산을 변경하면 현재 대화의 한도 검증이 다시 적용되는지 확인한다.
4. 최근 고액 수령 시나리오에 예산을 명시해 과거 중앙값과 최근 변화를 비교한다.
5. 공직자 부조 예외·계약 심사 상황은 **법률·직무 10개**에서 각각 선택한다.
6. 근거 보기를 열고 관계 연구는 직접 금액 통계가 아니라는 점을 설명한다.
7. 가상 시나리오 전환 시 다른 인물의 예산·직무 조건이 이어지지 않는지 확인한다.

## 2. 예외 시연

- **동명이인:** 이름과 소속·관계가 다른 후보를 분리하고 사용자가 확인할 때까지 기록을 연결하지 않는다.
- **공직자 직무 관련성:** 기존 법률 모듈은 내부적으로 보존되지만, 과거 v4 전용 온보딩 화면은 제거되었다. 별도 직업 설정 화면의 최종 통합은 아직 완료되지 않았다.
- **예산 미입력:** 관계의 의미만 분석하며 행동 금액을 임의 확정하지 않는다.
- **비금전적 도움:** 도움을 현금으로 환산하지 않는다. 사용자가 특별히 챙길 의향을 밝힌 경우에만 선택지 변경을 검토한다.
- **실모델 장애:** 오류를 감추지 않는다. 오프라인 고정 시나리오로만 시연한다.

## 3. 대체 시연

Codyssey 연결이 되지 않으면 **마음결 AI 자유 상담의 20개 고정 시나리오**를 사용한다. 기존 `/v4/` 별도 화면이나 `/v4/api/docs`는 더 이상 외부 경로로 제공하지 않는다.

실제 모델 해석 품질과 로컬 Windows 브라우저 E2E는 별도 확인이 필요하며, 자동 테스트 통과만으로 완료되었다고 발표하지 않는다.

## 4. 평가위원 질의응답

**Q. ChatGPT에 축의금 질문하는 것과 무엇이 다른가요?** — 사용자 개인 이력·예산·공개 통계의 근거를 구분하며 직업 동의와 관계 위험을 별도 규칙으로 검사합니다. 특정 법적 판단을 생성형 모델에게 전적으로 맡기지 않습니다.

**Q. 5만원이면 무조건 괜찮나요?** — 아닙니다. 특정 조건에서의 현금 경조사비 **가액 기준**일 뿐이며 예외 요건과 이해관계·기관 규정에 따라 금액 이하도 문제가 될 수 있습니다.

**Q. 사용자의 직업이 진짜인가요?** — 아닙니다. 자기신고 합성 데모이며 실제 신원 인증·재직 증명은 없습니다.

**Q. AI가 추측한 계약 관계를 사실로 판단하나요?** — 아니요. 추정 단서와 사용자가 확인한 조건을 구분하고, 추가 확인 또는 보류로 이어지도록 설계했습니다.

**Q. 외부 LLM에 개인정보가 전송되나요?** — 자유 상담 모드에서는 합성 관계 데이터가 코디세이 모델로 전송될 수 있습니다. 별도 정책 엔진의 선택적 분석은 사용자 동의 없이는 외부 호출하지 않습니다. **자유서술 자체에 개인정보가 있을 수 있으므로 이름·실제 민감정보를 입력하지 않도록 안내**합니다.

**Q. 상용 서비스인가요?** — 아닙니다. 로그인/실제 인증, 실데이터 보안, 전체 CRUD의 단일 DB 연동, 브라우저 E2E 등은 남아 있습니다.
