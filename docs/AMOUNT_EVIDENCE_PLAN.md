# 2026년 경조사 금액 근거·CPI 환산 구현 계획

## 목적과 제약

- 기존 금액 추천·관계 신호·예산 상한·법률 보류 동작을 유지한다.
- 공개 설문, 실제 송금, 예식장 가격, CPI를 **서로 다른 성격의 자료**로 구분한다.
- 과거 개인 거래는 원본 금액을 유지하고 2026년 9월 CPI 기준 비교용 값을 계산한다.
- RAG의 문서 검색 점수가 높다는 이유만으로 금액 추천의 직접 기준으로 사용하지 않는다.

## 단계별 구현

1. `data/knowledge_base.json`에 가연·소비자원·CPI 설명 자료 추가 및 농협 통계 보강.
2. `data/consumer_price_index.json`에 검증된 지수와 출처를 저장.
3. `app/inflation.py`에서 `과거 금액 × (2026-09 지수 / 과거 지수)`를 계산.
4. `app/recommender.py`의 과거 중앙값 비교에만 환산값을 적용. 개인 기록 원본 합계는 그대로 유지.
5. 근거 응답에 환산 기준월·월별/연평균/미환산 건수를 표시.
6. 테스트: CPI 월별·연평균·미확보·기준 이후 경계, 원본 보존, 예산·법률 상한, 미확인 설문의 금액 기준 적용 금지.

## 환산 정책

- 기준 월: **2026-09**, 전국 총지수 **120.43** (2020=100).
- 지급월 지수가 있으면 월별 CPI를 사용한다.
- 지급월 자료가 없지만 해당 연도 연평균이 있으면 **근사치**로 계산하며 `annual` 표기를 반환한다.
- 2016년 이전, 미래 기준월 또는 공개 지수 누락은 지어내지 않고 명목 금액을 반환하며 `unavailable` 또는 `after_reference`로 표시한다.
- 과거의 '10만원 응답자 61.8%' 같은 설문 구간 분포 자체는 물가로 이동시키지 않는다. 인식 조사 원본 분포를 보존한다.
- 청탁금지법 가액은 물가로 환산하지 않는다. 당시·현재 법령을 별도로 검토한다.

## 후속 조사 및 미완료

- 조의금·돌잔치의 신뢰할 수 있는 조건별 금액 분포는 아직 확보하지 못했다. 확인 전에는 가짜 표본 또는 평균을 생성하지 않는다.
- 월별 CPI 장기 시계열 확보 시 연평균 근사를 월별로 대체할 수 있다.
- 추천 후보액 `AMOUNTS`의 변경은 이번 범위에서 제외한다. 별도 실험과 예산 경계 검증이 필요하다.
- 배포 전 통합 API 회귀 테스트 및 실제 LLM·브라우저 시연 검증이 필요하다.
