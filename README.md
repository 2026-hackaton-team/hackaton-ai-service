# 마음결 — 경조사 AI 추천 · 직무 관련성 검토 (통합 발표 시연)

> **48시간 해커톤 로컬 시연 프로젝트.** 이 문서는 **GitHub `develop`에 병합된 React + FastAPI + 마음결 v4 RAG 통합 버전**을 설명합니다. [통합 PR #3](https://github.com/2026-hackaton-team/hackaton-ai-service/pull/3)은 병합 완료되었으며, **`main` 배포·실서비스 인증·최종 브라우저 E2E 완료를 뜻하지는 않습니다.**

**한 줄 소개:** 경조사 금액만 답하는 AI가 아니라 **예산·관계 이력·공개 근거를 분리해 추천하고, 직업·계약·심사 이해관계가 의심되면 금액 추천을 보류하며 추가 사실을 확인하는 도우미**입니다.

[최종 발표 대본·실습 시나리오](docs/PRESENTATION_DEMO.md) · [상세 개발/미완료 상태](INTEGRATION_STATUS.md) · [통합 PR #3](https://github.com/2026-hackaton-team/hackaton-ai-service/pull/3)

## 발표 전에: 3가지 기능

1. **마음결 AI 자유 상담** — 가상 계정 선택 후 자연어로 이력·예산·참석·부고 질문. 서버에 계정별 대화가 저장됩니다. *실제 Codyssey LLM 키 및 네트워크가 필요하며, 실패 시 AI 답변을 모의 생성하지 않습니다.*
2. **마음결 법률·관계 분석(자유 상담 내부)** — 사용자 직업·담당 업무 + 동의된 상대 직업 범주 + 자유서술 관계 단서를 결합합니다. RAG 근거/조건/예산으로 추천·추가 질문·송금 보류를 구분합니다. **오프라인 설명만**으로 결정적 데모가 가능합니다.
3. **공유 경조사 추천** — 일정 화면에서 가상 소식을 등록하면 공유 범위와 참석 허용 조건을 만족하는 친구·친구의 친구에게 추천합니다. 이 범위에 포함되고 동의된 계정 연결로 확인된 직장동료는 추천 이유에 표시합니다. 기존 알림함의 공유 부고 기능도 별도로 유지됩니다.

## 한 번에 실행 (Windows / Mac)

Python과 Node.js가 설치된 상태에서 저장소 루트의 시작 파일을 실행합니다. 처음에는 필요한 Python 환경과 프런트 의존성을 설치하므로 인터넷 연결이 필요합니다.

**Windows PowerShell**

```powershell
.\window_start.cmd
```

**Mac 터미널** — 요청한 파일명 `.cmd`를 유지하되 내용은 POSIX 셸 스크립트입니다.

```sh
sh ./mac_start.cmd
```

공통 접속 주소는 `http://127.0.0.1:5173`이며, 서버와 화면을 함께 종료하려면 **Ctrl+C**를 누릅니다. `--check`를 붙이면 설치·서버 실행 없이 포트와 환경 상태만 확인합니다. `.venv`와 `node_modules`는 운영체제별로 설치하므로 다른 OS에서 만든 폴더를 복사하지 않습니다.

두 시작 파일은 Git 추적 대상입니다. 아래 내용은 필요한 경우 사용할 수 있는 수동 실행 방법입니다.

## 1. 처음부터 설치·실행 (Windows / macOS)

**사전 준비:** [Git](https://git-scm.com/downloads), **Python 3.12**, **Node.js 22 이상**, **Corepack**, 인터넷 연결이 필요합니다. `frontend/package.json`에 지정된 패키지 관리자는 **pnpm@11.25.0**입니다. Node.js 20 이하는 pnpm 11을 실행할 수 없습니다. Windows는 **PowerShell**, macOS는 **터미널(zsh 또는 bash)** 기준입니다. 기존 `proto_rag_llm` 단독 v4 폴더가 아닌 **이 GitHub 저장소**를 사용하세요. Python 가상환경은 저장소 밖에 만듭니다.

### 1-1. 저장소 클론 (Windows·macOS 공통)

원하는 작업 폴더에서 터미널을 열고 아래 순서대로 실행합니다.

```sh
git clone --branch develop https://github.com/2026-hackaton-team/hackaton-ai-service.git
cd hackaton-ai-service
git status --short --branch
```

현재 통합 시연 코드는 **`develop` 브랜치**에 있습니다. 처음 클론했다면 `git fetch`/`git pull`을 별도로 실행할 필요가 없습니다. **이미 클론한 저장소**에서는 루트에서 `git status --short --branch`로 변경사항을 확인한 후 `git switch develop` 및 `git pull --ff-only origin develop`을 사용하세요. 로컬 수정이 있다면 강제 초기화하거나 덮어쓰지 말고 먼저 보관하세요.

### 1-2. 백엔드 실행 — Windows (PowerShell, 터미널 1)

복제한 **저장소 루트**에서 실행합니다. Windows용 Python Launcher가 포함된 Python 3.12가 필요합니다.

```powershell
py -3.12 --version
$venv = Join-Path $env:USERPROFILE 'Documents\Codex\venvs\maeum-gyeol-integration'
$python = Join-Path $venv 'Scripts\python.exe'
if (-not (Test-Path -LiteralPath $python)) { py -3.12 -m venv $venv }
& $python -m pip install -r requirements.txt 'openai>=1.75,<3'
& $python -m uvicorn gyeongjosa_ai.api:app --host 127.0.0.1 --port 8000
```

### 1-3. 백엔드 실행 — macOS (터미널 1)

Windows 단계 **대신** 아래 명령을 실행합니다. `python3.12` 명령이 없다면 먼저 [Python 3.12](https://www.python.org/downloads/)를 설치하세요. 가상환경은 Windows와 마찬가지로 저장소 밖의 사용자 문서 폴더에 둡니다.

```bash
python3.12 --version
venv="$HOME/Documents/Codex/venvs/maeum-gyeol-integration"
python3.12 -m venv "$venv"
"$venv/bin/python" -m pip install -r requirements.txt 'openai>=1.75,<3'
"$venv/bin/python" -m uvicorn gyeongjosa_ai.api:app --host 127.0.0.1 --port 8000
```

백엔드가 실행 중인 **터미널 1은 그대로 열어 둡니다.** AI 자유 상담에서 실제 Codyssey 모델을 호출하려면 서버 실행 **전에** 운영체제에 맞게 `CODYSSEY_API_KEY`를 설정해야 합니다. Windows PowerShell은 `$env:CODYSSEY_API_KEY = '본인_키'`, macOS 터미널은 `export CODYSSEY_API_KEY='본인_키'` 형식입니다. 외부 관계 분석은 별도 `OPENAI_API_KEY`와 명시 동의가 필요합니다. **오프라인 v4 시연은 키 없이 가능**하며, 키를 GitHub·화면·로그에 노출하지 마세요.

### 1-4. 프런트엔드 실행 — Windows·macOS 공통 (터미널 2)

**새 터미널**을 열어 복제한 저장소 루트로 이동한 다음 아래 명령을 실행합니다. Windows PowerShell과 macOS 터미널 모두 동일합니다.

```sh
cd frontend
node --version
corepack --version
corepack pnpm --version
corepack pnpm install --frozen-lockfile
corepack pnpm dev
```

`corepack enable`이나 별도 전역 pnpm 설치는 필요하지 않습니다. 특히 Windows에서 `corepack enable` 실행 시 Node.js 설치 폴더에 대한 `EPERM` 권한 오류가 날 수 있으므로 **`corepack pnpm`** 명령을 사용하세요. `corepack` 명령 자체가 없다면 [Corepack 설치 안내](https://github.com/nodejs/corepack#how-to-install)에 따라 설치하세요. Node.js 25 이상에는 Corepack이 기본 포함되지 않을 수 있습니다. 버전 다운로드에는 네트워크 연결이 필요합니다.

`dev:demo`는 별도 프런트 모의 백엔드를 실행하므로 **통합 시연에는 사용하지 않습니다.** 백엔드(8000)와 프런트엔드(5173)는 **서로 다른 터미널에서 동시에 실행**해야 합니다. 이미 포트를 사용 중인 서버가 있다면 해당 서버를 정상 종료하세요.

### 1-5. 브라우저 접속 및 확인 (공통)

브라우저에서 **http://127.0.0.1:5173** 접속 → **마음결 AI 자유 상담**. 별도 v4 분석 화면은 제공하지 않습니다.

| 경로 | 목적 |
|---|---|
| `http://127.0.0.1:8000/api/health` | 통합 API 상태 (`status=ok`) |
| `http://127.0.0.1:5173` | 최종 통합 React UI |

### 공유 경조사 시연하기

**일정 → 공유된 경조사**에서 가상 계정을 선택하고 소식을 등록합니다. 기본값은 나만 보기이며, 다른 계정에 보여 주려면 공유 범위·공유 확인·관계별 참석 허용을 선택해야 합니다. 확인된 직장동료 추천 이유는 공유자 이름 공개와 관련 인물 추천 동의가 있을 때만 표시됩니다. 등록한 소식의 공유는 같은 화면에서 철회할 수 있으며 개인 일정에 자동으로 추가되지 않습니다.

직장동료라는 이유만으로 공유 범위를 넓히지는 않습니다. 직장동료도 현재는 직접 친구 또는 친구의 친구로 허용된 경우에 추천됩니다.

소식은 로컬 SQLite에 저장되는 합성 시연 자료입니다. 가상 계정 선택은 실제 인증이 아니므로 실제 개인정보를 입력하지 마세요. 시연 순서는 `docs/PRESENTATION_DEMO.md`의 공유 경조사 절을 참고하세요.

### AI 자유 상담에서 v4 가상 시연하기

통합 React의 **마음 AI → AI 자유 상담**에서 가상 계정 `U001`을 선택하고 새 대화를 시작합니다. 화면에서 **10개 가상 시나리오**를 선택하거나 자연어로 입력할 수 있습니다.

1. `가상 시나리오: 직장 동료 김도윤 결혼식에 참석해서 식사해요. 예산은 3만원이에요` — 기존 `P001`과 이력 조회, 3만원 상한 검증
2. `가상 시나리오: 공직자 부조 예외 성립 가정, 장례식 예산은 10만원이에요` — 기존 `P004`와 공식 근거를 사용한 조건부 가액 검토
3. `가상 시나리오: 계약 심사 거래처 부친상, 예산은 3만원이에요` — 기존 `P005` 가정에서 송금 추천 보류

기존 3개 외에 추가된 7개 특별 시나리오: **현직 담임교사 축의금**, **공무원 제공자와 민간 거래처**, **상대 직업 비공개**, **현금·조화 복합 제공**, **공직자 자녀 돌잔치**, **동명이인 상주 확인**, **계약 종료 후 직무 관계**입니다. 시연 질문은 `data/v4_chat_scenarios.json`에, 6명의 추가 합성 인물과 행사·공개 동의 정보는 `data/v4_special_fixtures.json`에 있습니다. 기존 데이터 JSON은 변경하지 않습니다.

10개 시연은 기존 v4 오프라인 정책·추천 엔진을 재사용하므로 별도의 외부 모델 키 없이 작동합니다. 그 외 자유 상담 기능은 종전대로 Codyssey LLM 연결이 필요할 수 있습니다. 가상 시연은 실제 사람의 직업·법적 사실을 확정하는 기능이 아니며, 시나리오 전환 시 기존 예산·관계 상태를 이어받지 않습니다. 기존 정책·추천 엔진은 내부에서 재사용하며 별도 v4 화면과 외부 경로는 제거되었습니다.

### 감정·관계 이력 기반 추가 시연 10개

`AI 자유 상담`의 `U001` 계정에서 **감정·관계 10개**를 펼쳐 실행합니다. 기존 법률·직무 10개와 합쳐 총 20개의 고정 시연입니다.

| 분류 | 주요 시연 입력 | 확인할 결과 |
|---|---|---|
| 내가 늘 더 많이 냄 | 10만원씩 낸 4회 vs 5만원씩 받은 4회 | 평균의 방향을 구분하고 상대를 비난하지 않음 |
| 상대가 늘 더 많이 냄 | 5만원씩 낸 4회 vs 10만원씩 받은 4회 | 보답을 강요하지 않음 |
| 소중한 친구 | 친밀도 5/5, 과거 3만원씩 교환 | 사용자가 기록한 친밀도와 예산을 구분 |
| 최근 고액 변화 | 5만원 패턴 뒤 20만원 수령 | 마지막 기록의 변화만 설명하고 의도를 추측하지 않음 |
| 최근 소액 변화 | 10만원 패턴 뒤 3만원 수령 | 관계 악화로 단정하지 않음 |
| 참석의 불균형 | 나 4회 참석, 상대 0회 참석 | 금액과 방문 이력을 분리 |
| 비금전적 도움 | 이사와 어려운 시기 도움 메모 | 도움을 금액으로 환산하지 않음 |
| 관계의 거리감 | 친밀도 5→2, 18개월 연락 없음 | 과거와 현재의 관계 메모를 구분 |
| 경제적 부담 | 평소 10만원, 이번 예산 3만원 | 예산을 초과하지 않음 |
| 주변의 눈치 | 동료 관행 10만원, 예산 5만원 | 검증되지 않은 모임 관행을 사회 평균으로 주장하지 않음 |

가상 인물 10명과 양방향 지급·수령 거래 63건, 인맥관리에서 사용자가 기록했다고 **가정한** 친밀도·참석·메모는 `data/v4_special_fixtures.json`에 고정되어 있습니다. 새 기록은 기존 원본 JSON을 변경하지 않고 서버에서 결합합니다. 인맥관리 화면에서 관계 메모를 수정하는 일반 기능이나 실제 상대방의 의도를 검증하는 기능은 이번 범위에 포함하지 않습니다.

통계처럼 제시되는 숫자는 **해당 가상 계정의 과거 거래 산술평균**이거나 **합성된 모임 관행**으로, 사회 전체 평균이 아닙니다. 금액 계산을 요청하지 않았거나 예산이 없으면 먼저 관계 분석만 제시하고, 예산이 들어오면 기존 v4 추천 엔진의 상한 검사를 통과한 금액만 안내합니다.

## 2. 권장 8분 발표 흐름

상세 조작은 반드시 **[발표용 데모 운영서](docs/PRESENTATION_DEMO.md)**를 참조하세요.

| 장면 | 실제 조작 | 검증할 포인트 |
|---|---|---|
| 문제 소개 | 일정·인맥·금액 메뉴 소개 | 기존 React UI 보존 |
| 자연어 상담 | 마음결 AI → `U001` 선택, 합성 질문 | 자유 질문·이력·추가 질문 구조. *실모델 키 필요* |
| 소식 발견 | 상단 알림함 → 공유 소식 카드 | 공유 범위와 관계 조건 |
| 예산 배려 | AI 자유 상담 → `직장 동료 결혼식` 시나리오 → 예산 `30000`으로 변경해 **다시 제출** | 추천액은 3만원 초과 금지; 후보 없으면 금전 추천 없음 |
| 법적 조건 | AI 자유 상담 → `공직자 부조 예외 (가정)` | 공식 자료 검증 후 **조건부 5만원** 재평가 |
| 위험 탐지 | AI 자유 상담 → `계약 심사 이해충돌 (가정)` | 거래 위험 시 금액 보류 |
| 양방향 분석 | `U001`의 직업/담당업무를 공무원·계약업무로 등록 → 자연어 “저는 시청 계약 담당자이고 상대방은 제가 심사하는 거래처 직원입니다” → 미확인/확인 비교 | 사실과 추측 분리·기관 규정 검토 |
| 근거 투명성 | 적용 근거/제외 근거·RAG 검색 결과 확인 | 왜 계산했거나 보류했는지 추적 |

**주의 1:** 프리셋을 누르면 예산을 초기화하므로 **먼저 프리셋 → 예산 수정 → 재제출** 순서로 진행하세요.

**주의 2:** v4의 가상 법적 시나리오는 `scenario_id != default`일 때 명시된 합성 가정을 사용합니다. 실제 본인·상대의 직업 정보를 반영하는 장면에서는 **`default`로 되돌리세요.**

**주의 3:** v4 화면의 `AI 설명 방식`은 **오프라인 설명만**, `외부 LLM 분석 동의`는 **해제**하면 인터넷 없이 법률 근거·예산·자연어 단서의 결정적 시연이 가능합니다.

## 3. 핵심 설계 / 데이터 계약

```text
React (frontend/) ── /api/* ─── FastAPI (gyeongjosa_ai) ── 가상 계정/대화 SQLite + 합성 데이터
       └──────────── /v4/* ── v4 FastAPI (app/) ── 프로필 SQLite + 근거 TF-IDF + 정책/추천
```

- v4는 공개 자료를 수동 재서술한 소규모 지식베이스를 **한국어 문자 n-그램 TF-IDF**로 검색합니다. 벡터 DB나 실시간 법령 수집은 아직 없습니다.
- 추천액은 확인된 예산을 넘지 않으며, 법적 확인이 부족할 때는 `NEEDS_FACTS` / `NEEDS_EXPERT_REVIEW` 등의 **보류 상태**가 가능합니다. 일반 참고액과 실제 송금 추천액을 구분합니다.
- 상대 직업 분류는 **친구 연결·추천 목적 이용 허용·공개 범위**가 모두 충족된 경우에만 서버 정책에 사용합니다. 자기신고 직업만으로 실제 신분이나 적법성을 보증하지 않습니다.
- v4 자연어 관계 입력은 해당 API 처리 시 프로필 DB에 저장하지 않으며, 외부 LLM 전송은 선택적 동의가 필요합니다. **자유 상담 채팅은 대화 본문을 서버에 저장하므로 실제 개인·직무 민감정보를 입력하지 마세요.**
- 부고와 AI 자유 상담은 다른 합성 시연 데이터 범위를 사용합니다. **가상 계정 선택 후 인맥·일정·장부는 SQLite 단일 작업공간을 이용하지만, 로그인·친구·공유 소식은 별도 저장소입니다.**

## 5. 개인정보·법적 고지

**모든 사람·기관·거래는 시연용 합성 데이터입니다.** 외부 공개 서비스를 목적으로 하지 않으며 실사용 데이터/실제 개인정보는 입력하지 않습니다. 직업은 자기신고이며 신분 인증은 없습니다. 특히 청탁금지법상 조건부 현금 경조사비 **5만원 기준은 무조건적인 허용 금액이 아닙니다.** 예외 요건과 직무 관련성에 따라 금액이 적어도 허용되지 않을 수 있습니다.

### 인맥·일정·장부의 서버 단일 원천

마음결 AI에서 **가상 계정**을 선택하면 인맥·일정·장부의 저장·조회에 계정별 서버 SQLite 작업공간을 사용합니다. 처음 연결한 계정은 화면 상단에서 **기존 브라우저 기록 서버로 이전** 또는 **빈 서버 공간 시작** 중 하나를 선택해야 합니다. 과거 localStorage 데이터는 백업으로 보관하며 자동 덮어쓰기·삭제하지 않습니다. 서버에 저장된 친밀도(1~5점)·특별 관리 여부·양방향 거래 이력은 일반 자유 상담 개인화 추천에 사용합니다.

로그인 프로필·친구 요청·공유 소식 등은 여전히 별도 로컬/서버 시연 저장소에 있습니다. 가상 계정 선택 헤더는 실제 인증이 아니므로 외부에 공개하지 마세요. 자세한 범위와 이전 절차는 [작업 공간 DB 안내](docs/WORKSPACE_STORAGE.md)를 참조하세요.

### 관계 개인화 추천과 인간관계 RAG
- 친밀도, 최근 고액 수령, 지급·수령 차이, 현재 관계의 변화, 사용자의 특별한 의향을 금액 후보 순위에 반영합니다.
- 인간관계 연구자료 6개는 설명용 RAG 근거이며 적정 금액의 기준값으로 사용하지 않습니다.
- 추천 금액의 기준값과 조정 이유를 AI 자유 상담에 표시합니다. 예산·법률 위험 제한은 항상 우선합니다.
- 기존 법률·직무·감정 시나리오 20개는 자유 상담에서 유지하되, 별도 v4 화면은 제거됩니다.
