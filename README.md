# 마음결

AI 기반 경조사 알림 서비스를 위한 해커톤용 React 앱입니다. 일정과 인맥, 주고받은 금액을 하나의 흐름으로 연결하고, 관계 기록을 참고한 제안을 제공합니다.

## 실행

Windows PowerShell에서는 `npm` 대신 `npm.cmd`를 사용하세요. 예: `npm.cmd run dev:demo`.

Node.js 22 이상 환경에서 프로젝트 폴더로 이동한 뒤 실행합니다.

```bash
npm install
npm run dev
```

터미널에 표시되는 로컬 주소를 엽니다. 기본 주소는 `http://127.0.0.1:5173`입니다. pnpm을 사용하는 경우 `pnpm install`, `pnpm dev`로 실행할 수 있습니다. 프론트만 켠 경우 AI의 ‘브라우저 기록 체험’을 선택하면 서버 없이 사용할 수 있습니다.

**FastAPI 모의 AI까지 함께 실행**하려면 Python 3.11 이상도 설치한 후 아래 명령을 사용합니다. DB와 AI 키가 필요하지 않습니다.

```bash
npm run setup:demo   # 최초 한 번: .venv 생성과 Python 의존성 설치
npm run dev:demo     # React와 FastAPI 함께 실행, 종료는 Ctrl+C
```

화면은 `http://127.0.0.1:5173/#ai`, API 문서는 `http://127.0.0.1:8000/docs`입니다. 상세 실행 방법·포트 변경·실제 AI 전환·DB 교체 위치는 [FastAPI 데모 안내](docs/FASTAPI_DEMO.md)를 참고하세요.

```bash
npm run build    # dist/에 배포용 정적 파일 생성
npm run preview  # 빌드 결과 확인
npm test         # 도메인 로직 테스트
```

React 19, Vite 6, Lucide 아이콘을 사용합니다. Vite는 개발 서버와 정적 빌드를 담당합니다. 별도 API 키나 환경변수 없이 체험할 수 있습니다.

## 제공 기능

- **사이드바**: PC에서는 메뉴를 아이콘만 남기고 접거나 펼칠 수 있고, 모바일에서는 메뉴 열기·닫기를 제공합니다. 테마와 계정 관리는 상단에서만 사용합니다.
- **참석 상태**: 참석·불참 두 항목을 사용합니다. 기존 참석 예정 값은 참석으로 표시하고, 미정 기록은 임의로 판정하지 않고 선택할 수 있도록 유지합니다.
- **홈**: 가까운 경조사 2건과 마음 AI 대화창을 위아래로 배치합니다. PC는 자연스럽게 페이지를 스크롤하고, 모바일은 화면 높이에 맞춰 표시합니다. 긴 대화는 대화창 안에서 스크롤합니다. 나머지 일정은 전체 보기에서 확인합니다.
- **일정 관리**: 월별 달력과 유형 필터, 참석 여부, 일정 직접 등록·수정·삭제, 행사 전 알림 시점 설정을 제공합니다.
- **인맥 관리**: 가족·친구·직장동료·거래처를 선택하거나 기타에서 관계를 직접 입력합니다(공란은 기타). 중요도는 매우 중요·중요·보통이며, 중요한 인연 필터에 상위 두 단계를 포함합니다. 마지막 만남과 교류 기록, 사람별 경조사·금액 이력을 조회합니다.
- **금액·통계**: 보낸 금액과 받은 금액을 기록·수정·삭제하고, 사람·행사·기간으로 검색합니다. 월별·연도별 지출과 유형별 통계를 실제 기록으로 계산합니다. CSV 가져오기·내보내기를 제공합니다.
- **마음 AI**: 브라우저 기록 체험 또는 FastAPI 서버 가상데이터를 선택합니다. 금액 제안, 참석·불참 대응, 축하·위로 문구, 경조사 우선순위와 근거를 확인하고 서버 요청의 대기·취소·재시도를 지원합니다.
- **알림**: 상단 알림함의 읽음 관리와 브라우저 알림을 제공합니다. 브라우저 알림은 권한을 허용하고 **앱을 열어 둔 동안** 설정한 날짜부터 하루 한 번 전달됩니다.
- **계정**: PC·모바일 오른쪽 위 계정 아이콘에서 체험용 회원가입·로그인·로그아웃을 사용할 수 있습니다.
- **분위기 전환**: 기본은 밝은 아이보리 배경·흰 카드·딥그린 버튼에 짙은 글자를 사용하며 경사에는 로즈색을 곁들입니다. 자동 모드에서 오늘부터 **3일 이내 장례식**이 있으면 기존의 어두운 숲빛으로 전환합니다. 따뜻한 분위기와 차분한 분위기를 직접 선택할 수도 있습니다.

## 캘린더

일정 상세의 **캘린더 저장**은 알림 설정을 포함한 `.ics` 파일을 내려받습니다. 외부 캘린더에 가져와 사용할 수 있으며, 실제 알림 동작은 해당 캘린더 앱의 설정에 따릅니다.

## 금액 기록 수정·삭제와 CSV

금액·통계의 장부 오른쪽 **관리**에서 연필로 기록을 수정하고, 휴지통으로 내용을 확인한 뒤 삭제합니다. 수정·삭제는 사람별 이력과 통계에도 반영됩니다. 인맥과 일정은 삭제하지 않습니다.

- **CSV 내보내기**: 현재 조회 결과(기간·유형·검색 적용) 또는 전체 기록을 선택합니다. 한글 엑셀에서 열 수 있도록 UTF-8 BOM으로 저장하고, 수식처럼 해석될 수 있는 텍스트는 일반 텍스트로 내보냅니다.
- **CSV 가져오기**: 양식을 내려받아 작성하거나, 이전에 내보낸 파일을 선택합니다. 최대 2MB·5,000건이며 UTF-8, CP949, BOM이 있는 UTF-16 파일을 읽습니다.
- 필수 열은 `이름,행사유형,날짜,구분,금액`입니다. 선택 열은 `기록ID,인맥ID,관계,그룹,행사ID,메모`입니다. 날짜 예시는 `2026-10-31`, 구분은 `보낸 마음/받은 마음` 또는 `지출/수입`, 금액은 1원~10억 원의 정수입니다.
- 가져오기 전에 기록과 새로 등록할 인맥을 미리 보여 줍니다. 같은 이름의 인맥이 여러 명이면 인맥ID 또는 관계·그룹으로 구분해야 합니다. 기존 인맥 정보는 CSV로 덮어쓰지 않습니다.
- 같은 기록ID는 중복 제외하며 기존 기록을 수정하지 않습니다. ID가 없는 행은 인맥·유형·날짜·구분·금액·메모·행사 연결이 같은 기록을 중복 제외합니다. 내용이 같아도 별개의 거래라면 서로 다른 기록ID를 사용합니다.
- 오류가 있는 파일은 전체 저장을 막습니다. 다른 브라우저의 행사ID처럼 존재하지 않는 일정은 안내 후 연결 없이 가져오며, 일정을 자동 생성하지 않습니다.

모든 변경과 CSV 처리는 현재 브라우저에서 수행합니다. 서버·DB·계정별 데이터 격리를 제공하는 기능은 아닙니다.

## 체험 데이터와 구현 범위

초기 인물·금액·일정은 모두 가상 데이터이며 **2026년 10월 30일**을 기준으로 구성했습니다. 앱의 오늘 날짜는 실제 서울 날짜를 사용하므로 이후에는 샘플 일정이 지난 일정으로 표시됩니다.

데이터와 계정 정보는 이 브라우저의 `localStorage`에 저장됩니다. 일정·인맥·금액은 **체험 계정 간에도 같은 브라우저 데이터를 공유**하며, 계정별로 격리하거나 다른 기기와 동기화하지 않습니다. 브라우저 데이터를 지우면 저장 내용도 사라집니다.

회원가입과 로그인은 서버 인증이 아닌 브라우저 체험 기능입니다. 비밀번호는 무작위 salt와 PBKDF2 해시로 저장하지만 실제 서비스의 접근 제어를 제공하지 않습니다. AI의 브라우저 모드는 외부 전송 없이 동작합니다. 서버 모드는 질문과 선택한 서버 인맥 ID를 FastAPI에 전송하며, 기본 모의 응답은 외부 AI를 호출하지 않습니다. 선택적으로 서버의 OpenAI 설정을 켜면 질문과 가상 근거로 실제 AI를 호출할 수 있습니다. 실제 AI 키를 사용한 검증은 하지 않았습니다. 앱이 닫힌 뒤의 백그라운드 푸시 발송은 구현하지 않았습니다.

실서비스로 확장하려면 다음 연결이 필요합니다.

- 서버 기반 회원 인증, 계정별 권한 검사와 데이터베이스
- 서버에서 호출하는 생성형 AI 모델과 사용자 데이터 처리 정책
- 예약 작업, Web Push 구독과 서비스 워커를 통한 앱 종료 후 알림

AI API 키나 인증 비밀값은 프런트엔드 코드·`VITE_*` 환경변수에 넣지 않고 서버에서 관리해야 합니다.

## 백엔드 연결 준비

[백엔드 연결 명세](docs/BACKEND_INTEGRATION.md)에 일반 CRUD·인증의 연결이 필요한 기능과 제안 API를 정리했습니다. AI는 별도 `backend/`의 FastAPI 및 `src/services/aiChat.js`로 실제 HTTP 연결을 구현했습니다. 일반 데이터 저장은 여전히 브라우저 방식이며, AI 가상 데이터와 합쳐지지 않습니다.

현재 앱의 저장 접근은 `src/services/workspaceStorage.js`로 분리했고, CSV의 인맥·금액 묶음 저장도 이 모듈을 사용합니다. 일반 CRUD 서버를 붙일 때는 인증 초기화·비동기 로딩·저장 성공/실패 표시를 추가하고 서버 응답을 기준으로 상태를 갱신해야 합니다. `.env.example`에는 공개 설정만, `backend/.env.example`에는 서버 전용 설정 예시를 둡니다. 운영 배포·DB·실제 인증·백그라운드 푸시 구현은 포함하지 않습니다. 기존 Sites 배포는 정적 웹이므로 FastAPI 전체 데모는 PC에서 실행합니다.


## 최근 화면 개선

- 일정 등록: 이름·관계·그룹 검색과 방향키/Enter 선택, 검색 결과에서 선택해야 저장됩니다. 새 인맥 등록도 유지합니다.
- 체험 회원가입: 아이디·비밀번호·비밀번호 확인·이름·전화번호·이메일. 아이디/이메일 중복과 전화번호 형식을 검사하며, 기존 이메일 전용 계정 로그인도 유지합니다. 서버 가입·전화번호/이메일 인증은 아직 연결하지 않았습니다.
- 경조사 예절: 사이드바에 고정 안내를 추가하고 어른 생신(환갑·칠순·팔순), 아기 축하(돌·백일) 등 비슷한 자리를 묶었습니다. 가족·종교·현장 안내를 우선합니다.
- CSV: 금액 추가 버튼과 분리해 장부 하단 ‘파일로 기록 관리’에 모았습니다. 내보내기의 조회 결과/전체 선택과 가져오기 미리보기는 유지합니다.
- 후속 개선은 [서비스 전환 점검 제안](docs/SERVICE_REVIEW.md)에 제안만 정리했습니다.
